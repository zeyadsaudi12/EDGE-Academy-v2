# EDGE Academy

منصة تعليمية عربية مبنية بـ Node.js وExpress وMongoDB، وتُنشر على Vercel.

## هيكل المشروع

- `server.js`: نقطة تشغيل الخادم، والـmiddleware، ومسارات الصفحات.
- `config/`: إعداد الاتصال بقاعدة البيانات.
- `routes/`: تعريف مسارات الـAPI فقط.
- `controllers/`: منطق كل جزء من المنصة.
- `models/`: نماذج MongoDB.
- `middleware/`: الجلسات والصلاحيات والتحقق والرفع ومعالجة الأخطاء.
- `scripts/create-admin.js`: إنشاء أو تحديث حساب المدير من متغيرات البيئة المحلية.
- صفحات `*.html`: واجهات المنصة.
- `script.js` و`style.css`: السلوك والستايل المشترك للواجهة.
- `imges/` و`img/`: الأصول المستخدمة في الواجهة.

## التشغيل محلياً

1. انسخ `.env.example` إلى `.env` وأضف القيم المطلوبة.
2. شغّل `npm install`.
3. شغّل `npm run dev`.
4. افتح `http://localhost:3000`.

## متغيرات البيئة

| المتغير | الاستخدام |
| --- | --- |
| `MONGODB_URI` | الاتصال بقاعدة MongoDB |
| `JWT_SECRET` | مفتاح توقيع جلسات الدخول، 32 حرفاً على الأقل |
| `CLOUDINARY_*` | رفع الصور والملفات |
| `OPENAI_API_KEY` | تفعيل مساعد الذكاء الاصطناعي، اختياري |
| `OPENAI_MODEL` | اسم الموديل، مثل `gpt-5-mini`، اختياري |

لا تحفظ مفاتيح API أو ملف `.env` في Git.

## أوامر مفيدة

- `npm run dev`: تشغيل المنصة محلياً.
- `npm run create-admin`: إنشاء/تحديث المدير باستخدام متغيرات `ADMIN_*`.
- `npm start`: تشغيل الخادم في بيئة الإنتاج.
